# Rhythm & Rails website

Open `index.html` in a browser to preview the responsive holiday edition. Keep `hennessy-favicon.svg` alongside it for the browser tab icon.

The photographs are illustrative. Menu items, prices, events, address, hours, contact details, booking, payments, careers, delivery, and social links need confirmed business information or integrations before launch. Fonts and photos are loaded from external services and require an internet connection.

For GitHub Pages, put these files in the root of a repository, then enable Pages for the default branch in the repository settings. This package has not been published.

The scroll-scrubbed 4K background uses footage by Andi Farruku on Pexels: https://www.pexels.com/video/a-man-pouring-a-shot-of-liquor-into-a-glass-8242751/ . The video streams from Pexels and requires internet access; the illustration remains as a fallback. See https://www.pexels.com/license/ .
